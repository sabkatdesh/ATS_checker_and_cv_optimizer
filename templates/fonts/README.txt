Bangla font files for WeasyPrint PDF rendering.

Required fonts (OFL licence, free to bundle):

  HindSiliguri-Regular.ttf
  HindSiliguri-Bold.ttf

Download from Google Fonts:
  https://fonts.google.com/specimen/Hind+Siliguri

Place the .ttf files in this directory. If they are absent, WeasyPrint falls
back to a system sans-serif font. Latin text renders correctly without these
files; Bangla glyphs require them.

Optional (for richer Bangla coverage):
  NotoSansBengali-Regular.ttf
  https://fonts.google.com/noto/specimen/Noto+Sans+Bengali
